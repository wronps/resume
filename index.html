API evolution at scale

Built a knowledge base with 1.6M change events across 214K APIs, release-level static call graphs, and an AST-based import resolver. Mined 37K real-world repositories from the 224M-repository pool in The Stack v3.

From diagnosis to repair

Combined spectrum-based fault localization with differential execution tracing. Categorized 90K API-change instances using an 18-category taxonomy and LLM-assisted annotation.

Controlled agent evaluation

Benchmarked 3 LLMs under 7 information settings on 30 hand-verified tasks. Tracebacks and library-source tools improved Qwen3.8-27B from 0/30 to 14/30 resolved without code execution, and to 23/30 with code execution.

MAP → PLAN → NAVIGATE

Nov. — Dec. 2025

Local 2D SLAM
with Dynamic Path Planning

A LiDAR navigation pipeline, from probabilistic mapping to control on a physical Clearpath Jackal robot.

  • EKF-filtered odometry and Ceres scan-to-map optimization with bicubic B-spline interpolation.
  • 2-cm occupancy grids with Bresenham ray tracing; obstacle-inflated A*, gradient-descent path smoothing, and Pure Pursuit control.
  • Multi-threaded ROS integration, tested in Gazebo/RViz and on physical hardware.

STATE → POLICY → ACTION

Jan. — Mar. 2026 · Graduate coursework, CMPUT 628

Deep Reinforcement Learning

Implementing and evaluating value-based and policy-based methods, from DQN and Double DQN to PPO.

  • Experience replay, target networks, and multi-step TD returns (1, 5, 10). Image-based Jumping Tasks reached 99.7% success using Double DQN with 40-step returns.

  • Mean returns of about 3,200 on Walker2d-v4 and 2,700 on Ant-v4 over 3 seeds; ablations on entropy, target updates, and replay capacity.
